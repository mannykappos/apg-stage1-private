The historical checks are the 100 rows of the adopted exclusion list (`W1_EXCLUSION_LIST_v3.csv`, W-1B): the checks of earlier releases that the successor wrappers list as `EXCLUDED` and never run. `tools/historical_m10_s1.py` (builder tool, in the package) verifies the M10 archive's SHA-256, extracts it fresh, runs each distinct command once from the package root as the inventory did (`python -I <command>`), evaluates the three built-in coverage checks from the M10 wrapper's own definitions (without running the wrapper), and compares each row's exit code and last line with the ones the list records. For the three built-in rows the list records no exit code (`-`), so their exit check is only "not 0"; their last line, which states what is missing, is the comparison that decides them (section 9, mistake 12). This shows that the excluded checks still give their recorded results on M10: they are historical, not regressions of stage 1. The stage 1 regression itself (the 19 successor wrappers, section 3) runs on the stage 1 tree.
